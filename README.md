# Sprint 7 - Análisis de vehículos usados

Esta aplicación web desarrollada con Streamlit permite explorar un dataset de vehículos usados y analizar sus principales características.

La app carga los datos desde un archivo CSV, ofrece filtros interactivos por año, combustible, condición, tipo de vehículo, transmisión, precio y vehículos 4WD, y muestra métricas resumidas junto con visualizaciones como histogramas, gráficos de dispersión y tablas de datos.

## Funcionalidades principales
- Filtrado interactivo de registros
- Resumen de métricas como precio promedio, kilometraje promedio y año promedio
- Visualizaciones interactivas con Plotly
- Exploración de datos en formato tabla

## Cómo ejecutar la aplicación
1. Instala las dependencias con `pip install -r requirements.txt`
2. Ejecuta la aplicación con `streamlit run app.py`
